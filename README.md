Personal Portfolio Website
A modern, fully responsive portfolio that showcases my skills, projects and professional profile. It is built with plain HTML, CSS and JavaScript, with no frameworks or build tools.

Features

Separate sections for Home, About, Skills, Projects, Resume and Contact
Responsive layout that works on mobile, tablet and desktop
Mobile navigation menu with a hamburger toggle
Smooth scrolling and highlighting of the active section in the navbar
Typing animation in the hero section and animated skill bars
Project cards with images, descriptions and links to the To-Do app and Expense Tracker
Downloadable resume button
Contact form with validation for name, email and message
Respects light/dark system theme and reduced-motion settings

Tech used: HTML5, CSS3 (Flexbox, Grid, custom properties), JavaScript (ES6+).
